## 3. حالات القبول Given / When / Then

كل حالة لها بيانات تركيبية أولًا، وبيئة وصلاحيات فعلية عند الاختبار. يربط QA الحالة بالاختبار في PART 13؛ الحالة الحالية للجميع **Not run in this phase**.
