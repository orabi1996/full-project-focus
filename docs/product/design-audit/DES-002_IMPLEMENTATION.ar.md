# DES-002 — تصحيح عرض أمان الحساب

التاريخ: 9 سبتمبر 2026. هذه أول نقطة تنفيذ في خطة تحسين التصميم، وتغلق مسار **إزالة الادعاءات الأمنية غير المنفذة**. لا تفعّل إدارة الهوية أو تغيير كلمة المرور أو MFA.

## المشكلة والسلوك الجديد

كان تبويب الأمان يعرض نجاح تغيير كلمة المرور بعد مؤقت، ونجاح إنهاء الجلسات بمجرد رسالة، وحالة MFA محلية تبدأ بمفعلة، مع جهاز وموقع وIP ثابتة.

أصبح التبويب يعرض:

- تغيير كلمة المرور غير متاح من هذه الشاشة؛ لا توجد حقول تجمع كلمات مرور بلا تنفيذ.
- حالة MFA لم يُتحقق منها؛ لا تدعي الشاشة أنها مفعلة أو متوقفة، ولا تعرض زر تبديل شكليًا.
- إدارة الجلسات غير متاحة هنا؛ أزيل الجهاز والموقع والـIP وحالة «نشط الآن» المصطنعة.
- النسخة التجريبية لها توضيح صريح؛ تستخدم حالة demo الفعلية من AuthContext.
- محتوى الأمان بالعربية والإنجليزية، وعناوين وأوصاف واضحة، ونص أساسي 16px. اتجاه النافذة يتبع اللغة، مع حد ارتفاع وتمرير داخلي.

الوصول: القائمة الخاصة بالحساب ← إعدادات الحساب والأمان وكلمة المرور ← الأمان.

## حدود النقطة

لا تُرسل طلبات تغيير بيانات اعتماد أو إنهاء جلسات. هذا تنفيذ لبديل «إتاحة محدودة واضحة» في الخطة؛ يظل ربط تلك العمليات بمزود الهوية عملًا لاحقًا يحتاج نتيجة مؤكدة وإعادة تحقق ومعالجة فشل. لا يثبت التبويب الحالي صحة MFA ولا ينفي تفعيلها خارج هذه الشاشة.

تفضيلات الإشعارات والثيم وبقية الوحدات ليست ضمن هذه النقطة؛ لا تُعتبر رسائل الحفظ فيها قد أُصلحت بهذه الدفعة. ملاحظات التقرير الأصلي وتغطية المصدر فيه خط أساس تاريخي؛ لا تُحدث hashes الأصلية لتبدو أنها تصف الكود الجديد.

## التحقق

- أربعة اختبارات عرض تغطي العربية والإنجليزية، في التجربة وخارجها؛ تتحقق من غياب حقول كلمات المرور وأزرار تغيير الأمان والبيانات المصطنعة، ومن ظهور الحالة غير المتحقق منها.
- اختبار متصفح جديد عبر الدخول التجريبي والقائمة الحقيقية، يفتح الأمان ويتنقل بين التبويبات ويعود إليه ويغلقه. يشغله GitHub Actions على الكمبيوتر والجوال ضمن بوابة الجودة.
- فحص TypeScript وESLint للملفات المتغيرة وبناء الإنتاج قبل التسليم. النتيجة النهائية لاختبارات GitHub مرتبطة بالـcommit الذي يضيف هذه النقطة، وتراجع قبل الانتقال لنقطة أخرى.
- الاختبارات الآلية لا تعوض الجولة البصرية الشاملة المعلقة في تقرير التصميم.

## ملف التغيير

`AccountSecurityModal` يركب `AccountSecurityPanel` مستقلًا للعرض. لا توجد dependencies جديدة أو migrations أو تغييرات صلاحيات. حذفنا معالجات النجاح الوهمية بدل الإبقاء عليها خلف أزرار معطلة. يمكن إعادة فحص النقطة عبر الاختبار المخصص دون حساب حقيقي أو أسرار.

النقطة التالية حسب الأولوية: **DES-003 — تمييز حالة التكامل الحقيقية من المحاكاة**، بعد تأكيد رفع هذه النقطة ونتيجة فحوصها.
