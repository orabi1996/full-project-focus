# نظام الموارد البشرية المؤسسي المتكامل (HRMS Enterprise Solution)

منصة سحابية متكاملة لإدارة الموارد البشرية، الرواتب، الحضور والانصراف، والخدمة الذاتية للمؤسسات والشركات، مبنية وفق أحدث المعايير ومطابقة لأنظمة العمل واللوائح المعتمدة بالمملكة العربية السعودية (متوافقة مع نظام العمل، حماية الأجور WPS، منصة قوى، والتأمينات الاجتماعية GOSI).

## 🏗️ الوحدات الوظيفية العشرين (M01 - M20)

| الكود | الوحدة | الوصف والوظائف الرئيسية |
|:---|:---|:---|
| **M01** | **الصفحة الرئيسية ولوحات المتابعة** | بطاقات المؤشرات الذكية، المهام العاجلة، الإعلانات، ومؤشر الالتزام بالحضور الأسبوعي (Recharts). |
| **M02** | **المنشأة والهيكل التنظيمي** | إدارة الشركات الفرعية، الأقسام، المواقع الجغرافية المزودة بالسياج الجغرافي (Geofencing)، والمخطط الهيكلي التفاعلي. |
| **M03** | **إدارة الموظفين والملف 360°** | سجل الموظفين، معالج الإضافة (5-Step Wizard)، بطاقات الملف الشامل 360°، وتصدير Excel/CSV. |
| **M04** | **الوصول والأمان والصلاحيات** | مصفوفة صلاحيات ديناميكية (RBAC)، نطاقات البيانات (Self, Team, Department, All)، ومبدل الأدوار الفوري. |
| **M05** | **الطلبات ومحرك الاعتمادات** | صندوق اعتمادات فوري للمديرين (قبول/رفض/إعادة للتصحيح)، مصمم سلاسل الموافقات، وسجل زمني تفصيلي. |
| **M06** | **الإجازات والعطلات** | احتساب الأرصدة التلقائي، حجز الرصيد الفوري، طلب الإجازات، وتقويم إجازات الفريق التفاعلي. |
| **M07** | **الحضور والانصراف اللحظي** | تسجيل الحضور بالبصمة الجغرافية GPS، معالجة التأخير والغياب، وطلبات تصحيح البصمة. |
| **M08** | **الدوامات وجدولة العمل** | تعريف الورديات (ثابت، مرن، فترتان)، نوافذ السماح، وتقويم الجدولة التفاعلي للأسبوع والشهر. |
| **M09** | **أجهزة الحضور والمواقع** | ربط أجهزة البصمة السحابية (ZKTeco/Anviz)، واستيراد ملفات البصمة الخام مع فحص التكرارات (Idempotency). |
| **M10** | **مسيرات الرواتب الشهرية** | محرك احتساب الرواتب بنظام 30 يوم والتقويمي، حساب الإضافي (1.5x)، التأمينات (GOSI)، وتوليد قسائم الراتب. |
| **M11** | **السلف والمخالصات النهائية** | جدولة أقساط السلف، معالج مخالصة نهاية الخدمة (EOSB Calculator) وفق المادتين 84 و 85 من نظام العمل. |
| **M12** | **إدارة النفقات والمصروفات** | مطالبات المصروفات، رفع الفواتير، فحص حدود السياسات المانعة والتحذيرية، والترحيل المحاسبي. |
| **M13** | **إدارة الأداء 360°** | دورات التقييم، التقييم الذاتي وتقييم المدير والزملاء، مصفوفة توزيع الأوزان 100%، وتقارير الأداء. |
| **M14** | **تخطيط القوى العاملة** | نمذجة التكاليف التقديرية للمرتبات، خطط التعيين والإحلال، ومقارنة المخطط بالفعلي. |
| **M15** | **التوظيف ونظام تتبع المتقدمين (ATS)** | لوحة متابعة المرشحين التفاعلية (Kanban Pipeline)، إدارة ونشر الوظائف، وإصدار عروض العمل الرقمية. |
| **M16** | **العهد والأصول والوثائق** | سجل العهد والأجهزة، تتبع إخلاء الطرف عند الاستقالة، ومكتبة وثائق وسياسات المنشأة وإقرارات القراءة. |
| **M17** | **التقارير ومولد الاستعلامات** | كتالوج التقارير القياسية، أداة بناء التقارير المخصصة (Custom Query Builder)، والتصدير بصيغ متعددة. |
| **M18** | **التكاملات والقيود المحاسبية** | مركز قيود اليومية الآلية، الربط مع أنظمة ERP (Odoo, SAP, Zoho, QuickBooks)، ومفاتيح API وWebhooks. |
| **M19** | **الإشعارات وسجل التدقيق** | مركز الإشعارات الفوري، وسجل تدقيق غير قابل للتعديل (Append-Only Audit Log) يوثق الحركات والعمليات. |
| **M20** | **الخدمة الذاتية وتطبيق الجوال** | واجهة جوال تفاعلية (ESS Mobile View) لتسجيل الحضور بالـ GPS، مراجعة الراتب، وتقديم الطلبات. |

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **الواجهة الأمامية**: React 19, TypeScript 5, Vite 8, TanStack Router / TanStack Start
- **التصميم والتنسيق**: Tailwind CSS 4, shadcn/ui components, Lucide Icons, Recharts Analytics
- **قاعدة البيانات والأمان**: Supabase (PostgreSQL + Row Level Security Policies + Database Migrations)
- **التدويل واللغات**: الدعم الكامل للغتين العربية (RTL) والإنجليزية (LTR) مع الوضع الليلي والنهاري.
